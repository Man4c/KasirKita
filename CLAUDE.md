# Konteks Project

Project ini adalah **KasirKita POS** (Aplikasi Kasir & POS Multi-Platform Web & Mobile untuk UMKM).

## Sebelum mulai kerja

1. Baca `docs/index.md`.
2. Baca `docs/context.md`.
3. Baca `docs/PRD-KasirKita.md`.
4. Baca modul task terkait di `plans/`.
5. Baca `graphify-out/GRAPH_REPORT.md` jika tersedia.
6. Baca `graphify-out/graph.json` jika tersedia untuk memahami arsitektur kode.

## Setelah sesi kerja atau ada keputusan penting

Update `docs/context.md` dan modul `plan.md` terkait di `plans/` dengan:

- progress terbaru
- keputusan arsitektur baru
- perubahan penting pada UI/logic/storage/API
- catatan verifikasi atau test yang sudah dijalankan

## Aturan Kerja

- **Frontend & UI/UX Craft:** WAJIB selalu menggunakan skill `impeccable` untuk setiap pekerjaan frontend (Web React & Mobile React Native), perancangan UI, tata letak, komponen, dan perbaikan tampilan.
- Jangan refactor besar tanpa alasan kuat.
- Ikuti struktur dan pola kode yang sudah ada.
- Jangan menghapus perubahan user yang tidak terkait task.
- Setelah mengubah kode, jalankan verifikasi sesuai stack project.
