# UI/UX & Frontend Craft Rule

Whenever working on any frontend, UI, UX, layout, styling, interaction, or component task (including Web React.js + Tailwind and Mobile React Native Expo):
- **ALWAYS activate and use the `impeccable` skill**.
- Follow `impeccable` quality standards: strong visual hierarchy, touch-first ergonomics, appropriate typography for currency/tables, responsive layouts, accessibility, and clean dark/light UI.
- Use `shape`, `polish`, `audit`, `critique`, and other `impeccable` workflows when creating or refining surfaces.
